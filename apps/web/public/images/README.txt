VITO Med & Aesthetics — Image Folders
======================================

Drop your images into the correct folder below.
The website will automatically pick them up.
Use JPG or PNG format. Name the file clearly!

📁 team/
   - dr-precious.jpg       → Dr Precious Garnett (founder photo)
   - staff-1.jpg           → Other team member photos
   Name each file by the person's name so it's easy to find.

📁 gallery/
   - clinic-reception.jpg  → Front desk / waiting area
   - treatment-room.jpg    → Treatment room photos
   - before-after-1.jpg    → Before & after results (rename per treatment)
   - event-1.jpg           → Any event or open day photos
   Add as many as you like — the gallery will show all of them.

📁 services/
   - iv-drip.jpg           → IV Vitamin Drip treatment image
   - botox.jpg             → Botox / anti-wrinkle image
   - skin-peel.jpg         → Chemical peel / facial image
   - travel-clinic.jpg     → Travel clinic image
   - weight-loss.jpg       → Weight management image
   These show on the Services page next to each treatment.

📁 blog/
   - blog-post-1.jpg       → Featured image for first blog post
   - blog-post-2.jpg       → Featured image for second blog post
   Name them to match the blog post topic (e.g. skin-glow-blog.jpg)

TIP: Use landscape/wide images (1920x1080 or similar) for hero images.
     Use portrait/square images (1:1 or 4:5) for team and gallery photos.
